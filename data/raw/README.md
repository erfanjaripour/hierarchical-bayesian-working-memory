\## Description



Individual-trial data from three experiments investigating visual working-memory precision using continuous-report tasks.



Experiments:

\- Exp1: colors, scrolling response

\- Exp2: orientations, rotation response

\- ExpS3: colors, color wheel response



\## Variables



| Variable | Description |

|---|---|

| experiment | Experiment identifier |

| stims | Stimulus type |
